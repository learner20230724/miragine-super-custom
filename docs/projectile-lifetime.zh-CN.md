# 魔法师／吸血鬼弹丸寿命

[English](projectile-lifetime.en.md)

此项是用户指定的自定义规则，不是原版数值。原始恢复代码、生成数据及旧仓库不变；地图中的距离使用世界单位，不是屏幕像素。

| 参数 | 当前设置 |
|---|---:|
| 适用兵种 | 吸血鬼 ID 9、魔法师 ID 12；红蓝双方 |
| 地图宽 | 4500 |
| 目标飞行距离 | 地图宽 × 1.1 = 4950 |
| 弹速（不变） | 20 世界单位／弹丸处理步 |
| 发射延迟（默认不变） | 5 弹丸处理步 |
| 新弹丸初始寿命 | 253 弹丸处理步；原版 100 |
| 默认开火横向范围（不变） | 5 × 60 = 300 |
| 最后留在场景中的最大位移 | 4960；未提前命中／落空时 |

寿命 = 发射延迟 + ceil(地图宽 × 倍率 ÷ 弹速绝对值)。地图宽采用核心按原 AS3 整数规则转换后的实际宽度。只消除近整数的浮点计算误差，真实不足一整步的部分向上取整。默认需 248 次飞行更新，再加 5 次延迟，共 253。极端数值饱和到 JavaScript 安全整数上限，此时不保证仍覆盖目标距离。

原有更新顺序不变：延迟也消耗寿命；寿命已为 0 的那次仍先移动、再删除。因此默认最后留存位移是 4960，删除步骤内还可能推进到 4980，但不会保留该位置到下一渲染快照。30 Hz 是全局逻辑频率；原版动态列表顺序可能跳过某个弹丸的一次处理，所以不能保证精确的现实秒数。倍速只改变等待时间，不扩大世界距离。

**不会提高开火射程，也不保证每发飞满 4950。** 仍然只有靠近目标到原有范围才开火，跨过原目标横坐标时照常结算并移除，纵向错过也照常移除。其他兵种和水晶仍用原寿命。

## 配置与开发

`config/custom.json` 中的显式覆盖：

```json
"overrides": {
  "casterProjectileLifetime": { "mapWidths": 1.1, "unitIds": [9, 12] }
}
```

调整 `mapWidths` 后重新启动源码应用；只影响新发射弹丸，不重置已经在飞行的弹丸。F2 的其他参数应用会保留该配置，但此扩展本身未新增面板控件。删除该覆盖可恢复启动时原寿命；使用「回到原版」也会为后续对局恢复原规则，磁盘配置不被改写，重启后仍按磁盘覆盖启动。

实现入口为 `src/extensions/projectile-lifetime.mjs`，通过 `src/app/main.mjs` 的对局工厂接入。只按实例包装原攻击回调并修改 `attack.life`，不改恢复类或全局原型；重新生成不会覆盖它。定向回归：`node --test --test-isolation=none tests/projectile-lifetime.test.mjs`。
