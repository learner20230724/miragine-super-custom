# 魔法师／吸血鬼／水晶弹丸寿命

[English](projectile-lifetime.en.md)

这是自定义规则，不是原版数值；不改开火射程、弹速、伤害、冷却或生成数据。距离是世界单位，不是屏幕像素。已发布 v0.6.0-preview.1 包含吸血鬼／魔法师延寿；水晶延寿与[新命中规则](combat-hits.zh-CN.md)自 v0.6.1-preview.1 引入，并纳入 v0.6.2-preview.1 发布候选；旧 v0.6.0 EXE 不含这两项新规则。实际发布与验收状态以对应 Release 交付记录为准。

## 默认参数与实际距离

| 参数 | 吸血鬼 ID 9／魔法师 ID 12 | 红蓝水晶 |
|---|---:|---:|
| 寿命策略 | 地图宽 × 1.1 换算 | 固定 `baseLifeFrames` |
| 地图宽／目标行程 | 4500／4950 | 地图宽不参与换算 |
| 弹速（不变） | 20 世界单位／弹丸处理步 | 20 世界单位／弹丸处理步 |
| 默认发射延迟（不变） | 5 步 | 0 步 |
| 新弹丸初始寿命 | 253 步；原版 100 | 253 步；原版 100 |
| 最后留在场景中的最大行程 | 4960 | 5060 |
| 删除步骤内可能达到的行程 | 4980 | 5080 |

表中最大值假定没有提前碰撞；新命中规则允许斜向直线弹道，因此**行程不等于横向位移**。普通攻击使用独立的延迟结算，不按此表推算命中距离。修女 ID 6 的弹丸寿命仍为原值 100。

吸血鬼／魔法师寿命 = 发射延迟 + ceil(地图宽 × 倍率 ÷ 弹速绝对值)。地图宽采用核心按原 AS3 整数规则转换后的实际宽度。只消除近整数的浮点误差，真实不足一整步的部分向上取整。默认需要 248 次飞行更新加 5 次延迟，共 253。极端数值饱和到 JavaScript 安全整数上限，此时不保证仍覆盖目标距离。

水晶的 253 是**包括延迟在内的固定总预算**，不会随地图宽、弹速或延迟自动换算。延迟增大会减少可飞行步数。两种策略均保留原寿命更新顺序：延迟消耗寿命；寿命已经为 0 的那次仍先推进、再删除，该最终位置不留到下一渲染快照。30 Hz 是全局逻辑频率；原版动态列表顺序可能跳过某个弹丸的一次处理，因此不保证精确的现实秒数。倍速只改变等待时间，不增加世界距离。

**延寿不会提高开火射程，也不保证每发飞满预算。** 当前命中扩展在碰到第一个敌人后移除弹丸；关闭命中扩展但保留延寿时，仍按原版“跨过锁定目标横坐标并检查纵差”的方式提前移除。两个扩展相互独立。

## 配置与恢复

在 `config/custom.json` 的 `overrides` 中保留其他配置，并设置：

```json
"casterProjectileLifetime": {
  "mapWidths": 1.1,
  "unitIds": [9, 12],
  "baseLifeFrames": 253
}
```

- `mapWidths` 必须为正有限数；`unitIds` 为不重复的 0～15 号兵种列表。
- `baseLifeFrames` 是可选正安全整数；省略时水晶沿用原寿命。它不是额外加上的步数。
- 修改文件后重启源码应用；只影响之后新发射的弹丸，不重置已在飞行中的剩余寿命。F2 其他参数应用保留此配置，寿命项暂无面板控件。
- 删除整个 `casterProjectileLifetime` 覆盖可恢复启动时的原寿命，但不自动关闭独立的 `combatHitRules`。要恢复原始战斗规则，须一并删除两个覆盖，或通过 F2「回到原版」为后续对局恢复原规则。面板不改写磁盘，重启仍读取磁盘覆盖。

## 开发入口

`src/extensions/projectile-lifetime.mjs` 由 `src/app/main.mjs` 对局工厂安装，只按实例包装攻击回调并修改 `attack.life`；不改恢复类或全局原型，重新生成不会覆盖它。命中行为另见 `src/extensions/combat-hits.mjs`。

```sh
node --test --test-isolation=none tests/projectile-lifetime.test.mjs
```
