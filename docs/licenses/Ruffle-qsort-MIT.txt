Applicable component: src/core/avm2-sort.mjs

This component is a JavaScript adaptation of Ruffle v0.7.1's qsort function:
https://github.com/ruffle-rs/ruffle/blob/v0.7.1/core/src/avm2/globals/array.rs

Ruffle identifies that implementation as a port of the Adobe avmplus QuickSort
partition algorithm:
https://github.com/adobe/avmplus/blob/master/core/ArrayClass.cpp

Ruffle offers its code under MIT or Apache-2.0, at the recipient's option. This
project uses the MIT option for this adapted component. The adaptation changes
Rust slice handling into JavaScript indexed ranges and exposes only the dense-
array numeric-depth sorting needed by the recovered game. It is not a complete
implementation of Flash Array.sortOn or evidence of Adobe player runtime parity.
