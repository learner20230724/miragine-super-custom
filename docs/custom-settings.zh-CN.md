# 自定义设置与沙盒

[English](custom-settings.en.md) · [默认参数表](parameters.zh-CN.md) · [时钟说明](time-control.zh-CN.md)

本页描述 v0.3.0-preview.1 的源码功能；实际发行包与验证结果以对应 Release 为准。默认数值仍来自超级版，不把自定义编辑伪装成原版规则。

## 打开、暂停与收起

- 左下角仅保留「设置 F2」「暂停／继续」小按钮。按 F2 打开右侧设置；宽窗口并排、窄窗口上下排列，游戏保持比例，不用大面板覆盖战场。
- 打开设置默认暂停战斗，仍可缩放、移动观察镜头和编辑。点面板顶部「继续战斗」可解除编辑暂停，边看边调。
- F2、Esc 或「收起 ×」收起面板。收起只解除编辑暂停；手动暂停和 0 倍速不会被误解除。0 倍时需改为正倍速，或用左下角「继续」恢复此前的正倍速。
- 速度滑块／数值框支持 **0～20，步进 0.1**；快捷按钮为 0、1、2、4、8、12、20。速度即时生效，不必点击「应用本局」，也不属于规则预设。
- 显示上限、目标／实际速率、全图／跟随都收在面板中。F11 是窗口全屏，「全图」是紧凑战场取景，两者不同。

## 草稿、应用、保存是不同操作

| 操作 | 对当前战局的影响 | 后续行为 |
|---|---|---|
| 修改字段、载入预设、导入 JSON | 不应用 | 改变编辑草稿，并尝试保存草稿备份 |
| 撤销 | 不应用 | 撤销最近的草稿操作，最多保留 30 次；不是战斗回滚 |
| 恢复原版默认 | 不应用 | 将面板可编辑字段恢复为默认草稿；不删除预设 |
| 应用本局 | 明确修改当前局可生效的字段 | 同时设为本次运行的后续新局规则；开局字段等到下局 |
| 设为下局规则 | 当前局不变 | 本次运行之后的新局使用该草稿；不会仅因重启自动启用 |
| 按草稿开始新战局 | 明确结束当前局、开始新局 | 使用所选难度／单人或同机双人模式；重新开始前确认 |
| 另存为新预设／覆盖所选预设 | 不应用 | 保存命名规则，供日后载入；覆盖前确认 |
| 回到原版菜单 | 结束当前局，恢复完整原版运行配置 | 草稿与预设保留；不改写磁盘 `config/custom.json` |

“恢复原版默认”只重置面板中的字段；未展示的手工 `config/custom.json` 覆盖仍会保留到应用结果中。需要本次运行完全回到恢复的默认配置时，用「回到原版菜单」。重启仍照常读取磁盘 `config/custom.json`。

## 可调内容与生效时机

| 分区 | 可调项目 | 应用本局后的时机／边界 |
|---|---|---|
| 兵种（16 个，红蓝共用） | 名称、说明、生命、护甲类型／值、轻甲／重甲伤害、基础移速、射程、攻击间隔、命中延迟、费用、人口、招募增加收入 | 存量单位属性更新；费用／人口／收入只影响后续招募，已花费资源不退款；已有攻击冷却不重置，新投射物使用新延迟 |
| 经济／轮次 | 收入与每轮人口上限、双方开局金币、红方开局收入、首轮／后续轮长、自动招募检测间隔 | 开局值仅下局；当前轮次倒计时、金币、收入及剩余人口不重置；后续轮长与人口上限在下次轮次结算生效 |
| 共用倍率 | 移动倍率、射程倍率、攻击间隔倍率 | 对应基础属性按原计算方式生效，不改变 30 Hz 逻辑频率 |
| 水晶 | 双方生命、双方射程、红方两类伤害与攻击间隔 | 更新当前水晶；生命按所选策略，已有攻击冷却不重置 |
| 难度／蓝方（四档） | 蓝方开局收入／首轮人口、蓝水晶两类伤害／间隔、AI 克制选兵概率 | 当前难度的攻击属性可生效；开局资源仅下局；选兵概率在后续 AI 选兵时使用 |
| 自动行为 | 红／蓝自动招募、蓝方 AI 自动选兵 | 应用时同步；关闭 AI 选兵不冻结已有士兵的寻敌、移动或攻击 |

所有字段的界面提示标注单位、允许范围与生效时机。默认数值和四难度区别见[完整参数表](parameters.zh-CN.md)，不要把编辑器允许范围当作原版默认值。

### 时间、取整与生命策略

- **30 逻辑帧 = 1 游戏秒**。轮长和命中延迟均以游戏帧计，不是现实毫秒；倍速改变现实等待时间，不改帧数。
- 生效移速 = 基础移速 × 移动倍率；生效射程 = 基础射程 × 射程倍率。兵种攻击冷却帧 = `Math.trunc(基础攻击间隔 × 攻击间隔倍率)`；已有冷却保留。实际攻击还受目标、动作和命中延迟影响，不能据此编造统一的固定攻速。
- 默认「保持生命比例」按原当前生命／原上限的比例映射到新上限；「保留当前生命」仅改上限，不改当前生命。两种策略均保留原版可能出现的超额生命，不复活死亡单位。
- 切换到新难度需开始新局；编辑另一档难度不会把当前局偷偷切过去。

## 沙盒／刷兵

沙盒按钮直接作用于**当前已应用规则**，不会顺带应用尚未应用的草稿；仅在尚未结束的战局中可用。

- 选红／蓝阵营和兵种，单次生成 **1～100** 个士兵，使用原生成流程但免费：不扣金币／人口，也不增加收入。
- 自定义应用或沙盒操作启用后，自动与手动生成合计最多 **500 个兵种实体**，包含尚未移除的死亡动画。满额不再生成；这只是自定义模式的防卡死上限，未启用自定义的原版局没有此新增上限。
- 「清除所选阵营／双方士兵」需确认：删除士兵及相关攻击物，保留水晶，不退还资源，不可撤销。
- 可直接设置双方当前金币、收入和剩余人口；金币／收入范围 0～100,000,000，人口范围 0～10,000。这是沙盒输入范围，不是新的原版资源上限。
- 可立即选择双方招募兵种、切换双方招募及蓝方 AI 选兵。此处是当前局操作；长期预设请在「自动行为」页修改草稿再保存。
- 原版没有建筑建造、主动技能、固定关卡波次或条件增援编辑系统，因此不提供虚构入口。

## 预设、存储与备份

「预设／文件」页支持载入草稿、另存、覆盖、删除、导入和导出。最多 **25** 个命名预设，名称 1～80 个字符；单个导入文件不超过 **256 KiB**，预设库不超过 **2 MiB**。只接受白名单参数 JSON，不执行脚本。

| 环境／文件 | 保存内容与注意事项 |
|---|---|
| 桌面 `userdata/custom-settings.json` | 草稿与预设，通过受限 IPC 写入；不依赖每次启动的本地服务端口 |
| 浏览器 `localStorage` | 当前站点来源下的草稿与预设；换地址／端口或清站点数据后不可当作同一存储 |
| 包外 `config/custom.json` | 启动覆盖配置，不被面板写入或被预设替换 |
| 导出的 JSON | 可迁移的单份草稿；使用面板导入，不能直接替代 `config/custom.json` |

草稿备份不等于命名预设，命名预设也不是游戏进度存档：不保存当前兵队、资源、随机数状态或战斗进度。重启后加载到的草稿／预设**不会自动启用**。速度、暂停、显示上限和镜头选择不属于这些规则文件；启动默认 1 倍，避免意外以高速开局。

保存失败或文件损坏时会显示警告，当前内存草稿仍可导出；不要把“修改成功”当作“已可靠落盘”。桌面保存完成需后端确认；升级前备份两个自定义文件，重要预设建议额外导出 JSON。恢复、重新提取或生成原素材不会覆盖这些手工配置与预设。
