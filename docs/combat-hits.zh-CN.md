# 自定义战斗命中规则

[English](combat-hits.en.md)

这是为“真实弹道碰到谁打谁”和“大射程隔空普通攻击”启用的**新玩法**，不是恢复出的原版规则。此扩展自 v0.6.1-preview.1 引入，并纳入已发布的 v0.6.2-preview.1；旧 v0.6.0-preview.1 EXE 不包含它。发布与验收结果见[本版交付记录](releases/v0.6.2-preview.1.json)。恢复核心、默认兵种数据、素材、开火射程、攻击间隔、伤害／护甲公式、倍速与 30 Hz 逻辑频率均不改。

## 为什么原先可能一直攻击却不掉血？

原规则先允许纵向距离不超过 40 的单位开火，但攻击物跨过锁定目标横坐标时，只在纵差不超过 30 时伤害该目标；检查失败也移除攻击物。目标处于两者之间时，便可能连续落空，移动后才重新受伤。原版普通攻击也使用隐藏的移动攻击物，因此大射程还可能受到飞行时间和寿命限制。特效看起来重叠不等于旧逻辑已经命中。

此外，原伤害公式为 **对应护甲类型的伤害 − 护甲**，没有最低伤害兜底。相等仍是 0，小于护甲仍可能回血。本扩展保留这条规则，不把所有“不掉血”都当作命中错误，也不承诺任何攻击都能杀死任意自定义目标。

## 远程：直线弹道，首次接触结算

- 以武器类型 `fb`／`tb`／`storm` 识别远程弹丸；默认包括**修女 ID 6、吸血鬼 ID 9、魔法师 ID 12，以及红蓝水晶**，不单凭攻击范围大小分类。
- 原发射延迟结束时，朝原锁定目标当前的世界 XY 位置瞄准一次，随后直线飞行，不持续追踪。目标移动可以躲开；原目标死亡不会直接吞掉弹丸。
- 每个弹丸处理步检查上一位置到下一位置的**整段路径**与敌方圆形碰撞体，选择本步沿路径最先接触的对象，调用一次原伤害结算后移除弹丸。不是只检查更新终点，避免高速弹丸越过目标而漏判。
- 友军、死人和已离场对象不挡弹。前排敌人可以替后排挡弹；没有碰撞则继续飞，直到碰撞或寿命耗尽。
- 这是逻辑世界 XY 平面的圆形碰撞，不是 PNG 透明度逐像素检测，也不是屏幕像素碰撞。缩放、斜视角、贴图空白和空中姿势不改变下面的世界半径；视觉轮廓与碰撞体不保证完全重合。
- 扫掠检查的是弹丸路径与敌人在该处理时刻的位置，不是双方完整的跨帧运动轨迹。把兵种移速调到一帧跨过整条弹道时，仍可能越过弹丸；高射速和长延迟／寿命也会累积在途攻击，不保证极端参数下的固定帧率。

## 普通攻击：等待原延迟后结算锁定目标

其他没有上述独立弹丸的普通攻击，开火条件仍使用单位当前射程与原规则。攻击建立后等待原 `delayAttack`，再对仍存活、仍在场的锁定目标结算一次，不追加飞行距离、纵差或射程复查。这样调整为很大的射程时，“隔空砍”也能结算伤害；锁定对象死亡或离场则不造成伤害，不自动转移给另一个人。

这里只更换伤害判定，不修改攻击动画、冷却或伤害数值。没有额外最低伤害或保底命中伤害。

## 配置参数

| `overrides.combatHitRules` 参数 | 默认值 | 含义 |
|---|---|---|
| `projectiles` | `swept-first-enemy` | 弹道扫掠，首次接触敌人后结算并移除 |
| `ordinaryAttacks` | `delayed-target` | 普通攻击在原延迟后直接结算锁定目标 |
| `unitRadius` | 20 | 单位碰撞半径，世界单位 |
| `baseRadius` | 40 | 水晶碰撞半径，世界单位 |
| `projectileRadius` | 6 | 弹丸碰撞半径，世界单位 |

**20／40／6 是本改版明确新增的玩法参数，不是从 SWF 恢复的碰撞半径。** 接触判断使用目标与弹丸半径之和。它们不修改开火范围，也不随画面缩放改变。

当前启动配置如下；编辑 `config/custom.json` 后重启源码应用，不要覆盖生成的默认数据。已有其他手工配置应保留。

```json
{
  "schemaVersion": 1,
  "profile": "custom-combat-hits",
  "overrides": {
    "casterProjectileLifetime": {
      "mapWidths": 1.1,
      "unitIds": [9, 12],
      "baseLifeFrames": 253
    },
    "combatHitRules": {
      "projectiles": "swept-first-enemy",
      "ordinaryAttacks": "delayed-target",
      "unitRadius": 20,
      "baseRadius": 40,
      "projectileRadius": 6
    }
  }
}
```

两个扩展独立：水晶寿命固定 253 步，吸血鬼／魔法师按地图宽 1.1 倍换算；修女寿命不变，仍为 100。延迟也消耗弹丸寿命，碰撞可使弹丸提前消失，详细行程与取整见[弹丸寿命表](projectile-lifetime.zh-CN.md)。

命中参数暂无新增 F2 面板项。删除启动配置中的 `combatHitRules` 覆盖并重启，可恢复原命中规则，但保留独立寿命扩展；同时删除两个覆盖才撤回这两项改进，其他个人参数需另行恢复。v0.7.0-preview.1 候选的 F2「恢复原版默认」只恢复面板参数，保留这两项改进；「返回主菜单（结束本局）」只结束本局，保留设置，不再是撤回扩展的入口。面板不改写磁盘配置；本机保存值优先于启动文件的同名面板参数，见[设置与备份](custom-settings.zh-CN.md#预设兼容与备份)。

## 开发入口与定向检查

- `src/extensions/combat-hits.mjs`：独立的碰撞／普通攻击结算扩展。
- `src/extensions/projectile-lifetime.mjs`：独立寿命预算。
- `src/app/main.mjs`：对局工厂安装扩展。
- `tests/combat-hits.test.mjs`、`tests/projectile-lifetime.test.mjs`：定向回归；不会启动图形窗口。

```sh
node --test --test-isolation=none tests/combat-hits.test.mjs tests/projectile-lifetime.test.mjs
```
